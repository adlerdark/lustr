# Corrupt files

Some files are broken: they won't play, stop half-way, or show garbage. Instead of looking at them every time, mark them.

## Marking a video

Right-click it → **⚠ Mark as corrupt**. Select several first to mark them all at once.

A marked video gets the tag `corrupt.file` and disappears from every library view, for everyone. The file itself isn't touched.

## Finding and unmarking them

**Settings → Maintenance → Corrupt files** lists every marked video, with its library and files.

- **Unmark** one to bring it back, or tick several and **Unmark selected**.
- **Refresh** reloads the list.

> Note: if a file only fails in the browser, try another quality in the player first. A transcoded quality often plays files the browser can't. See [Watching videos](player.md#quality-direct-or-transcoded).
