# Quick tags

Quick tags are the buttons above each field in **Edit Metadata** and the cast attribute editor. One click adds the value, so you don't have to type it, and the spelling always comes out the same.

## Edit them

**Settings → Metadata → Edit Quick Tags**.

1. Pick a field on the left. **Add quick tags for this field** starts a list for a field that has none.
2. Type a value in **New tag…** and click **Add**. The box below shows how it will be saved.
3. Drag values to change their order, or click **×** to delete one. **Remove all quick tags for this field** empties the list.
4. Click **Save**.

## How values are written

lustr writes tags in lower case with dots instead of spaces: **Big Tits** is saved as `big.tits`. That keeps one spelling for each value, so filters and searches find them all. To keep a value exactly as you typed it, tick **keep exactly as typed** before adding it.

## Order

**Order when editing** sets the order of the buttons in Edit Metadata:

- **As listed here**: your own order.
- **Alphabetical (#, A–Z)**.

The list in the editor always keeps your own order.

> Note: removing a quick tag never changes any video's metadata. It only removes the button.
